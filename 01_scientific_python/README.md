# 科学计算工具

[返回首页](../README.md)

原目录“数据库学习”实际包含科学计算库笔记，因此按内容更名。NumPy 笔记也导入 pandas；SymPy 笔记需要扩展依赖。

| 脚本 | 内容提示 |
| --- | --- |
| [matplotlib_basics.py](matplotlib_basics.py) | 绘图方式、子图与图表练习 |
| [numpy_basics.py](numpy_basics.py) | NumPy 数组操作与 pandas 导入 |
| [scipy_examples.py](scipy_examples.py) | 优化、拟合、积分、微分方程与 FFT |
| [sympy_basics.py](sympy_basics.py) | 符号微积分与矩阵计算 |
